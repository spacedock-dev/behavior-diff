The important distinction today

The agent designs the experiment. It prepares the scenario, shared data, and checks before the run. Scripts stage and verify these inputs.

The Bash runner executes it. Fresh headless agents run the task. Python sends their evidence to a model for interpretation, then validates and renders the result.

Live mode changes execution, not the whole pipeline. It uses in-session subagents and self-reported actions, but shares Python extraction helpers and reporting.

Already present at import: the September 2 baseline already used a model for semantic extraction and shared Python helpers for live mode. Those are not later inventions. The original extractor was deliberately blind to the instruction diff; later entries show when edit context and frozen goals entered assessment.

How to read this history

Each entry is based on its commit message and code or instruction diff. “Inferred from the change” means the purpose is a conservative explanation of the implementation, not a recorded statement from its author. Report-only and maintenance changes are included, but are not presented as changes to trial behavior. This is a source-history audit, not evidence that historical model runs succeeded.
